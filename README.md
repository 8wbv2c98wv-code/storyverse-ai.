# StoryVerse AI — первая онлайн-демоверсия

Интерактивные истории на русском языке: каталог оригинальных персонажей, поиск, избранное, создание своего героя и сценарные диалоги.

## Как опубликовать на Vercel

1. Откройте https://vercel.com/new и войдите через GitHub.
2. Выберите репозиторий `storyverse-ai.` (точка в конце — часть текущего имени).
3. Выберите Framework Preset: **Other**.
4. Оставьте Root Directory: `./`; Output Directory: пусто (корень). Не задавайте команду сборки.
5. Нажмите **Deploy**.

Главная страница — `index.html`; весь код оформления и демо-чатов уже встроен в этот файл. Никакой платный API-ключ для демонстрации не нужен.

## Состояние проекта

- ✅ Каталог персонажей, фильтры, избранное и создание персонажа
- ✅ Переписка с готовыми **сценарными**, а не ИИ-ответами
- ✅ Сохранение данных только в браузере текущего устройства (`localStorage`)
- ⏳ Настоящие ответы ИИ через сервер
- ⏳ Регистрация, защищённая облачная база, модерация и ограничение количества запросов

**Важно:** этот сайт — прототип, а не готовый публичный сервис. Не вводите в чаты конфиденциальные данные; при очистке браузера переписки могут исчезнуть. Не публикуйте в GitHub секреты и ключи API. Перед включением платного ИИ для посетителей необходимо настроить авторизацию, ограничения запросов и защиту от злоупотреблений.
