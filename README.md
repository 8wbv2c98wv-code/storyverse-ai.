# StoryVerse AI — бесплатная тестовая версия

Веб-сайт на русском языке с оригинальными героями, поиском, избранным, созданием персонажей и локальным сохранением диалогов.

## Без расходов на ИИ

Вместо платного OpenAI API сайт теперь использует **Cloudflare Workers AI (Workers Free)**. Если подключение не выполнено, продолжают работать сценарные ответы деморежима. OpenAI API больше **не вызывается**.

Cloudflare Workers Free на 14 октября 2026 года даёт **10 000 Neurons в день** без оплаты; при достижении лимита следующие запросы не выполняются (до сброса лимита). Некоторые тяжёлые модели требуют платного аккаунта, но выбранная здесь модель `@cf/meta/llama-3.1-8b-instruct-fast` предназначена для обычного Workers AI. Сверяйте актуальные условия перед использованием: https://developers.cloudflare.com/workers-ai/platform/pricing/

1. Зарегистрируйтесь на https://dash.cloudflare.com/ и оставайтесь на **бесплатном тарифе Workers Free**. Не включайте Workers Paid и платный AI Gateway.
2. Откройте **Workers AI → Use REST API**. Следуйте https://developers.cloudflare.com/workers-ai/get-started/rest-api/
3. Создайте **Workers AI API Token** и скопируйте **Account ID**. Не отправляйте токен в чат и не коммитьте его в GitHub.
4. Откройте проект в Vercel → **Settings → Environment Variables** и добавьте для **Production**:
   - `CLOUDFLARE_ACCOUNT_ID` — идентификатор аккаунта Cloudflare (не пароль).
   - `CLOUDFLARE_AI_TOKEN` — секретный токен Workers AI, **Type Secret**.
   - `AI_ACCESS_CODE` — отдельный закрытый тестовый код, уже созданный ранее (оставьте его).
5. Удалите старую переменную `OPENAI_API_KEY` из Vercel или отзовите этот OpenAI-ключ — новая версия не использует его.
6. В Vercel → **Deployments** выполните **Redeploy** после изменения переменных.
7. При первой отправке сообщения сайт попросит `AI_ACCESS_CODE` для тестирования.

**Никакую платёжную карту для этого пути добавлять не нужно.** Не включайте сторонние платные модели. Бесплатный лимит и ассортимент моделей могут меняться.

## Что пока не реализовано

- Персонажи в деморежиме отвечают по сценариям; настоящие ответы появляются только после настройки Cloudflare.
- Переписки сейчас хранятся **локально в браузере**, не синхронизируются между устройствами.
- Последние 18 сообщений передаются модели в рамках одного запроса; долговременной памяти нет.
- Ограничение запросов и общий тестовый код подходят **только для закрытого тестирования**. Для публичного сервиса необходимы аккаунты, общие серверные лимиты, модерация и отдельная защита от злоупотреблений.
- Бесплатный **Vercel Hobby** предназначен для личных некоммерческих проектов: https://vercel.com/docs/plans/hobby . Для коммерческого запуска условия нужно проверить заново.

## Как опубликовать

Проект состоит из статической страницы `index.html` и серверных функций `api/chat.js`, `api/status.js`. В Vercel: Import GitHub repository → **Other** framework → Deploy. Никаких команд сборки не требуется.

Все секреты должны храниться только в Vercel Environment Variables и не должны попадать в GitHub.
