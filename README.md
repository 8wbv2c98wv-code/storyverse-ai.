# StoryVerse AI — первая онлайн-демоверсия

Интерактивные истории на русском языке: каталог оригинальных персонажей, поиск, избранное, создание своего героя и сценарные диалоги.

## Как опубликовать на Vercel

1. Откройте https://vercel.com/new и войдите через GitHub.
2. Выберите репозиторий `storyverse-ai.` (точка в конце — часть текущего имени).
3. Выберите Framework Preset: **Other**.
4. Оставьте Root Directory: `./`; Output Directory: пусто (корень). Не задавайте команду сборки.
5. Нажмите **Deploy**.

Главная страница — `index.html`; весь код оформления и демо-чатов уже встроен в этот файл. Никакой платный API-ключ для демонстрации не нужен.

## Состояние проекта

- ✅ Каталог персонажей, фильтры, избранное и создание персонажа
- ✅ Переписка с готовыми **сценарными**, а не ИИ-ответами
- ✅ Сохранение данных только в браузере текущего устройства (`localStorage`)
- ⏳ Настоящие ответы ИИ через сервер
- ⏳ Регистрация, защищённая облачная база, модерация и ограничение количества запросов

**Важно:** этот сайт — прототип, а не готовый публичный сервис. Не вводите в чаты конфиденциальные данные; при очистке браузера переписки могут исчезнуть. Не публикуйте в GitHub секреты и ключи API. Перед включением платного ИИ для посетителей необходимо настроить авторизацию, ограничения запросов и защиту от злоупотреблений.


## Подключение настоящего ИИ (закрытая бета)

Сайт и сценарные диалоги работают без ключей. Серверные обработчики живут в \`api/chat.js\` и \`api/status.js\`.

1. В [OpenAI API Platform](https://platform.openai.com/api-keys) создайте **обычный API-ключ проекта**, настройте биллинг и низкие лимиты расходов. Платформа API оплачивается отдельно от подписки ChatGPT. Никогда не вставляйте API-ключ в браузер, GitHub или чат.
2. В [Vercel](https://vercel.com/dashboard) откройте проект **storyverse-ai. → Settings → Environment Variables**.
3. Добавьте для **Production**:
   - \`OPENAI_API_KEY\` — секретный ключ OpenAI API.
   - \`AI_ACCESS_CODE\` — придуманный вами длинный непредсказуемый тестовый код (от 16 символов). Это **отдельный код**, не API-ключ.
   - \`OPENAI_MODEL\` (необязательно) — \`gpt-4.1-mini\`.
4. В **Deployments** разверните последнюю версию заново (**Redeploy**) — изменения переменных не влияют на уже опубликованную сборку.
5. На сайте появится статус «ИИ ПОДКЛЮЧЁН». При первой отправке сообщения сайт попросит **тестовый код доступа**. Код хранится только в оперативной памяти вкладки, а **API-ключ остаётся исключительно на сервере**.

**Безопасность:** это тестовая версия с общим кодом доступа, а не полноценная регистрация. Код можно передавать только доверенным тестировщикам. Встроенный лимит запросов действует в памяти отдельного серверного экземпляра и **не гарантирует** глобального ограничения трат. Для публичного запуска обязательны аккаунты, серверное хранилище, общая rate-limit база, модерация и ограничения расходов в API-проекте. Не публикуйте код доступа в описаниях проекта.

**Диалоги:** браузер сохраняет переписку только локально; модель видит последние 18 сообщений. Долговременная память и синхронизация между устройствами ещё не реализованы.
